PORTAFOLIO PROFESIONAL - HANSEL AAROM ROMAN ESCALANTE

ARCHIVOS:
- index.html: contenido de la página.
- styles.css: diseño y adaptación a celulares.
- script.js: menú móvil y filtros de experiencia.
- assets/perfil.jpg: fotografía de perfil recortada para retirar el marco exterior.

PARA VER LA PÁGINA EN TU COMPUTADORA:
1. Extrae la carpeta del archivo ZIP.
2. Abre index.html con Chrome, Edge o Firefox.

PARA PUBLICAR EN GITHUB PAGES:
1. Crea un repositorio público nuevo en GitHub.
2. Sube index.html, styles.css, script.js y la carpeta assets completa.
3. En el repositorio entra a Settings > Pages.
4. En Build and deployment selecciona Deploy from a branch.
5. Selecciona la rama main y la carpeta /(root), y guarda.
6. Espera a que GitHub publique el sitio.
